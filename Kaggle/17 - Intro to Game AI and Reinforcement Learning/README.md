This course covered the basics of game AI and acted as an entry point to reinforcement learning.

Topics:
- Play Connect Four (set up game environment, create game agent, and evaluate performance)
- One-Step Lookahead (game trees and heuristics)
- N-Step Lookahead (minimax algorithm)
- Reinforcement Learning (neural network, weights, (cumulative) reward, and game agent training)
